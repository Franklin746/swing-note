# スイング帳

iPhoneのホーム画面に置いて使う、ゴルフのスイングチェック用Webアプリです。App Storeは使いません。

- 写真アプリの動画を取り込み、番手ボタンを選んで保存
- スロー（1×・½×・¼×・⅛×）、コマ送り（押し続けると連続）、ループ、左右反転
- 直線・延長線・円・角度のガイド描画（角度は数値表示、拡大鏡つき）
- AI（MediaPipe）で骨格を検出し、前傾・ひじ・手首・ひざ・胸と腰の回転・体重の目安を表示
- アドレス／トップ／インパクト／フィニッシュを自動で推定（手動で調整可）
- レッスンの指摘に沿ったチェック（始動で頭が下がらない、インパクトで胸を開かない、両膝を伸ばしてインパクト、8：2のフィニッシュなど）
- 調子が良かったときの動画を「ベスト」に登録し、自動で比較・指摘
- 任意の2つのスイングを並べて／重ねて同期再生（最初・トップ・インパクト・テンポで合わせる）
- 打球の結果（打ち出し・曲がり・高さ・当たり）の記録と番手別の傾向、動画からの打ち出し推定（判別できたときのみ）
- レッスンメモから今の課題と練習ドリルを提示
- 質問チャット（Claude APIキーを入れるとアプリ内でAIが回答）

## 使えるようにする手順（GitHub Pages・無料）

1. GitHubのアカウントを作る（無料）。
2. 右上の「＋」→「New repository」。名前は例えば `swing-note`、**Public** を選んで作成。
3. 作ったリポジトリで「Add file」→「Upload files」（空のリポジトリなら「uploading an existing file」）。このフォルダの23個のファイルをすべて選んでアップロードし、「Commit changes」。フォルダはないので、iPhoneのファイルアプリからまとめて選べます。合計約32MBあるので、Wi-Fiでのアップロードがおすすめです。前の版をアップロード済みなら、同じ名前のファイルは上書きされます。
4. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」。数分で `https://ユーザー名.github.io/swing-note/` が公開されます。
5. iPhoneの **Safari** でそのURLを開き、共有ボタン →「ホーム画面に追加」。
6. ホーム画面のアイコンから起動して使います（ホーム画面から使うと、保存した動画が自動で消えにくくなります）。

公開されるのはアプリのプログラムだけです。動画・解析結果・レッスンメモ・APIキーはiPhoneの中だけに保存され、GitHubには上がりません。

## 外部への接続について

この版は、骨格解析のAI（MediaPipe）・AIモデル・フォントをすべてアプリと一緒に置いています。さらに、アプリが接続できる先を「このサイト自身」と「Anthropic（AIの回答を使うときだけ）」に制限する設定（Content-Security-Policy）を入れています。

- 骨格解析はiPhoneの中で動き、動画はどこにも送られません。
- MediaPipeには、処理時間などの利用統計をGoogleに送る仕組みが組み込まれていますが、上の制限でブロックされます（画像は含まれない統計ですが、送らない設定にしています）。
- 同梱したAIモデル `pose_landmarker_full.task` は、Googleが配布している公式ファイルと同じものです（SHA-256: `4eaa5eb7a98365221087693fcc286334cf0858e2eb6e15b506aa4a7ecdcec4ad`）。
- 同梱した部品のライセンスは `THIRD_PARTY_LICENSES.txt` にまとめています。

アプリを更新したいときは、同じリポジトリに新しいファイルを上書きでアップロードすれば、次にアプリを開いたときに反映されます。

## 最初にやること

1. 「練習」タブ →「まとめて貼り付け」で、レッスンメモを貼り付ける（「2026/3/28 レッスン」のような日付の行ごとに分けて保存されます）。
2. 「ベストを登録」で、調子が良かったときのスイング動画を入れる（後方・正面それぞれあると比較しやすい）。
3. 練習で撮った動画を「スイングを追加」→ 番手を選んで保存。自動で骨格解析 → マーカー設定 → レッスン項目のチェックまで進みます。

初回の骨格解析では、アプリと一緒に置いてあるAIモデル（約20MB）を読み込みます。以降はiPhoneに保存した分を使うので、オフラインでも動きます。

## 撮り方のコツ

- **後方**：飛球線の後ろ、手元の高さから。**正面**：飛球線と直角、胸の高さから。
- 頭から足まで全身が入るように、三脚などで固定する。
- カメラの「スロー」で撮ると、インパクト付近までコマ送りで見られます。打ち出しの推定もスロー動画向けです。
- 角度は1台のカメラ映像からのAI推定値です。毎回同じ位置から撮った動画どうしで比べてください。体重配分・頭の左右・ボール位置・フィニッシュの手の位置は正面の動画でチェックします。

## AIの回答（任意）

チャットの回答、練習メニュー作成、「AIに詳しく見てもらう」を使うにはClaude APIキーが必要です。
[APIキーの取得方法](https://platform.claude.com/docs/en/get-api-key) を見てキーを作り、アプリの「設定」→「APIキー」に貼り付けます。使った分だけ料金がかかります（Claudeアプリの有料プランとは別）。
キーがなくても、骨格解析・チェック・ベスト比較・ドリル提案はすべて使えます。チャットの質問は「Claudeで詳しく聞く」で、資料ごとClaudeアプリに引き継げます。

## ファイル構成

- `index.html` 画面とデザイン
- `app.js` 画面の動き
- `pose.js` 骨格推定（MediaPipe）と角度の計算
- `view.js` 動画の上の描画、タイムライン
- `coach.js` レッスン項目のチェック、ドリル、球筋、AI連携
- `util.js` 共通の部品
- `sw.js`、`manifest.webmanifest`、`*.png` ホーム画面アプリ用
- `mediapipe_vision.js`、`vision_wasm_*.js`、`vision_wasm_*.wasm` 骨格解析のAI（MediaPipe 1.0.1）
- `pose_landmarker_full.task` 骨格解析のAIモデル
- `barlow-condensed-*.woff2` 数字の表示に使うフォント
- `THIRD_PARTY_LICENSES.txt` 同梱した部品のライセンス
